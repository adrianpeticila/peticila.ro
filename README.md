# peticila.ro

My name, my domain, my business card.

One page. No framework, no build step, no cookie banner begging to follow you around. Hand-written HTML and CSS, plus just enough JavaScript to make the type fill the screen exactly.

This is the hub. Who I am, what I do, where to find me. Everything else I make links back here.

**Stack:** HTML, CSS, vanilla JS. GitHub Pages. Cloudflare DNS. That's the whole list. A personal site doesn't need a bundler. It needs a point of view.

Built and maintained with an AI pair, supervised by [Gorgona](https://github.com/adrianpeticila/gorgona), the operating system that runs all my brands.

Live: [peticila.ro](https://peticila.ro)
